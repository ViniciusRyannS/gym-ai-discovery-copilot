# Product Context

## Produto

Gym.AI é um copiloto conversacional de discovery técnico-comercial para times de
pré-vendas. O sistema conduz o levantamento por dez categorias, identifica
lacunas e gera documentos de apoio à decisão.

## Problema

Briefings incompletos e processos de discovery pouco padronizados aumentam
retrabalho, atrasam propostas e tornam a qualidade dependente da experiência
individual.

## Usuários

- Profissionais de pré-vendas;
- Arquitetos e especialistas técnicos;
- Consultores responsáveis por discoveries;
- Líderes que revisam entregáveis técnico-comerciais.

## Princípios

- IA apoia a decisão; não substitui revisão profissional;
- dados de usuários diferentes devem permanecer isolados;
- limitações experimentais devem ser comunicadas;
- o projeto deve ser reproduzível e demonstrável.
