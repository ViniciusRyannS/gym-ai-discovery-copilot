# Origem, autoria e continuidade

## Origem

O Gym.AI nasceu como projeto final do Pulse Mais para enfrentar uma dor de
pré-vendas técnico-comerciais: briefings incompletos, descobertas
inconsistentes, riscos encontrados tarde e retrabalho na preparação de
propostas.

O trabalho foi desenvolvido no contexto do Programa Pulse Mais, a partir de um
desafio proposto pela Clear IT. Essa descrição registra a origem do projeto e
não implica parceria comercial, patrocínio ou endosso institucional da versão
posterior mantida neste repositório.

A base conceitual veio das especificações elaboradas pelo grupo. O MVP usado na
entrega acadêmica foi reconstruído no Lovable com TanStack Start, Supabase e
Lovable AI Gateway.

## Continuidade pós-entrega

Após a entrega, Vinicius Ryann preservou uma cópia do workspace para conduzir
uma etapa de:

- estabilização;
- testes;
- documentação;
- segurança;
- modo de demonstração local;
- preparação para portfólio e apresentação.

As melhorias posteriores podem ser identificadas pelo histórico deste
repositório, sem alterar os créditos da autoria original.

## Relação com o workspace Lovable

O workspace original foi criado em uma conta pertencente a outro integrante.
Vinicius possui acesso administrativo ao projeto, mas não controle sobre a
conta proprietária. Este repositório é uma cópia independente destinada à
continuidade e preservação do trabalho.

Commits deste repositório não devem ser apresentados como sincronizados
automaticamente com o workspace Lovable original.

## Distribuição

publicação sob licença permissiva deve ser decidida considerando a autoria
