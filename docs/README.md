# Documentação do Gym.AI

Este diretório separa documentos atuais de registros históricos para evitar
que decisões antigas sejam confundidas com o estado atual do produto.

## Comece aqui

- [Manual do sistema](manual-do-sistema.md): funcionalidades, limitações,
  evoluções e integrantes;
- [Guia para mentores](guia-do-projeto-para-mentores.md): explicação acessível,
  tecnologias e exemplo completo;
- [Contexto para IAs](contexto-completo-para-ia.md): handoff abrangente e
  restrições contra afirmações não comprovadas;
- [Origem e autoria](project-origin.md): créditos, contexto institucional e
  continuidade;
- [Roteiro de demonstração](demo-script.md): percurso recomendado para uma
  apresentação curta.

## Histórico preservado

- `decisions/`: decisões arquiteturais tomadas em cada etapa;
- `specs/`: contratos de mudança no modelo Spec-as-Code;
- `sessions/`: evidências e resultados das sessões de implementação.

Esses três diretórios não são manuais atuais. Frases como “pendente” ou
“não publicado” dentro de um registro histórico descrevem o momento em que
aquela tarefa foi executada.
