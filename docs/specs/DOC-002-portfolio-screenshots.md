# DOC-002 — Screenshots de portfólio

## Objetivo

Apresentar visualmente a jornada pública do Gym.AI no README, usando capturas
reais fornecidas pelo responsável pelo portfólio.

## Decisão

- organizar as imagens em `docs/assets/screenshots`;
- apresentar briefing, conversa, entendimento e artefatos em ordem narrativa;
- usar legendas que expliquem valor, sem alegar capacidades não demonstradas;
- não alterar o produto ou o fluxo remoto de IA.

## Critérios de aceite

- [x] quatro imagens versionadas e legíveis;
- [x] nenhuma imagem expõe credencial ou dado pessoal;
- [x] README exibe a jornada em ordem coerente;
- [x] links locais das imagens foram validados;
- [x] formatação e CI permanecem verdes.

## Rollback

Reverter a entrega por novo commit, preservando o histórico publicado.
