# Demo Script

Este documento será detalhado depois da estabilização dos fluxos críticos.

## Pré-condições

- ambiente publicado disponível;
- usuário de demonstração confirmado;
- jornadas demo carregadas;
- gateway de IA funcional;
- nenhuma credencial visível na gravação.

## Fluxo preliminar

1. Entrar com usuário de demonstração;
2. apresentar o portfólio inicial;
3. criar um discovery;
4. responder às perguntas e mostrar a cobertura;
5. gerar entendimento executivo;
6. gerar um artefato;
7. reforçar o aviso de revisão humana.

## Demonstração pública

A rota `/demo` funciona como uma versão autocontida desse roteiro. Ela não exige
login, não persiste dados e não chama serviços de IA. Os dados exibidos são
simulados para demonstrar com previsibilidade a transformação de um briefing
incompleto em perguntas, cobertura, Entendimento Executivo e artefatos.
