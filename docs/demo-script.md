# Demo Script

Roteiro recomendado para apresentar o valor do Gym.AI em aproximadamente cinco
minutos.

## Pré-condições

- abrir a [demonstração pública](https://viniciusryanns-gym-ai-discovery-copilot.east-gigantspinosaurus.workers.dev/demo);
- não é necessário login nem gateway de IA;
- nenhuma credencial visível na gravação.

## Fluxo principal

1. explicar a dor: um briefing curto não sustenta uma proposta segura;
2. mostrar as dez categorias que estruturam o discovery;
3. iniciar o exemplo de retrabalho na produção;
4. percorrer as perguntas e apontar a evolução da cobertura;
5. abrir o Entendimento Executivo e destacar riscos e lacunas;
6. abrir os previews de PRD, ADR, Spec e User Stories;
7. reforçar que os dados são fictícios e exigem revisão humana.

## Exploração opcional

Para mostrar a interface completa, clique em **Acessar produto**, selecione
**Demonstração** e use `teste@email.com` / `teste123456`. Depois, abra a
conversa completa de exemplo.

## Demonstração pública

A rota `/demo` funciona como uma versão autocontida desse roteiro. Ela não exige
login, não persiste dados e não chama serviços de IA. Os dados exibidos são
simulados para demonstrar com previsibilidade a transformação de um briefing
incompleto em perguntas, cobertura, Entendimento Executivo e artefatos.
